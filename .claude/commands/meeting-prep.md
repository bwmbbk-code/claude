# 회의 예습

## 사전 조건

1. 인자 `$ARGUMENTS`를 파악. 비어 있거나 `next`이면 "다음 회의"를 찾습니다.

## 수행 단계

1. **대상 이벤트 탐색**
   - `next`: Calendar `list_events`로 지금 이후 첫 이벤트 1개.
   - 키워드: Calendar에서 향후 7일 내 이벤트 중 제목/설명에 키워드 매칭되는 첫 이벤트.
   - 찾지 못하면 "해당하는 이벤트가 없습니다" 후 중단.

2. **참석자 분석**
   - 이벤트의 참석자 이메일 목록 추출.
   - 각 참석자에 대해 Gmail `search_threads`에 `from:{email} OR to:{email} newer_than:30d`로 최근 대화 3개 제목 수집.
   - 외부 참석자면 (선택) 도메인에서 소속 추측.

3. **직전 대화 이력**
   - 이벤트 제목/주제 키워드로 Gmail과 Notion을 각각 검색. 관련 스레드·메모 상위 5개 타이틀 수집.

4. **안건 초안**
   - 이벤트 설명에 안건이 이미 있으면 그대로 인용. 없으면 지난 30일 대화 요약을 토대로 3~5개 bullet 안건 제안.

## 출력 포맷

```markdown
# 회의 예습: {이벤트 제목}

- **일시**: YYYY-MM-DD HH:MM–HH:MM ({N분 후})
- **장소/링크**: ...
- **참석자**: 이름 (소속/역할) — 최근 1개월 소통 {N건}

## 🗂 배경 (직전 대화 이력)
- [메일] 제목 — 날짜
- [Notion] 메모 제목 — 날짜

## 📋 안건 초안
1. ...
2. ...
3. ...

## 🧭 나의 입장/준비 포인트
- ...
- ...

## ❓ 물어볼 것
- ...
```
