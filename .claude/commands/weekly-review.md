# 주간 회고

## 사전 조건

1. `config.local.md`에서 사용자 이름, 주 Gmail, 기본 캘린더, Notion 작업 DB ID, GitHub 주 레포를 읽습니다.

## 수행 단계 (병렬)

1. **메일 흐름**: Gmail `search_threads`에 `newer_than:7d` 쿼리로 보낸 메일·받은 메일 볼륨을 확인. 중요 스레드 상위 10개 제목만 추출.
2. **일정 회고**: Calendar `list_events`로 지난 7일(오늘 −7일 ~ 오늘) 이벤트 전부 조회 → 카테고리(회의/외부/개인) 분류.
3. **커밋/PR**: GitHub `list_commits`, `list_pull_requests`로 지난 7일간 활동 조회 (주 레포 기준).
4. **메모**: Notion `notion-search`로 지난 7일 생성된 메모 타이틀 조회 (작업/아이디어 DB 포함).
5. **종합 분석**: 위 자료를 토대로 잘한 것 3, 막힌 것 3, 다음 주 우선순위 3을 뽑아냅니다.

## 출력 포맷

```markdown
# 주간 회고 ({월요일}-{일요일})

## 📊 이번 주 한눈에
- 메일: 받음 N / 보냄 N / 중요 처리 N
- 회의 시간: N시간 (내부 N / 외부 N)
- 커밋: N개 / PR: N개 머지
- 새 메모: N개

## ✅ 잘한 것
1. ...
2. ...
3. ...

## ⚠️ 막힌 것 / 반성
1. ...
2. ...
3. ...

## 🎯 다음 주 우선순위 Top 3
1. ...
2. ...
3. ...

## 🗒 기록에 남길 만한 순간
- ...
```

선택: 사용자가 "저장" 한 마디만 덧붙이면 결과 전체를 Notion 작업 DB에 "주간 회고 YYYY-WW" 제목으로 저장합니다.
