# 포스트 초안 작성

## 사전 조건

1. 인자 `$ARGUMENTS`가 비어 있으면 "초안 주제를 알려주세요"라고 안내하고 중단합니다.
2. `config.local.md`에서 **초안 저장 폴더 ID** (Google Drive)와 **블로그 주제 키워드**를 읽습니다.

## 수행 단계

1. 필요 시 `/content-research`에서 얻은 리서치 자료가 이번 대화에 있는지 확인합니다. 없으면 사용자에게 "먼저 리서치를 돌릴까요, 아니면 바로 초안을 쓸까요?"라고 한 번만 묻고, 지시에 따릅니다.
2. 아래 3개 포맷을 한 번에 생성합니다 (모두 한국어):
   - **블로그 글** (900~1,200자): 도입 → 핵심 3대 포인트 → 결론·행동 제안. H2로 섹션 구분.
   - **X 스레드** (5~7개 트윗): 훅 트윗 + 본론 + CTA. 각 280자 이내.
   - **LinkedIn 포스트** (400~600자): 1인칭, 짧은 문단, 줄바꿈 풍부, 말미에 질문 1개.
3. Drive `create_file`로 초안 저장 폴더 안에 **마크다운 파일 1개**(3개 포맷이 구분선 `---`으로 연결된 형태)를 생성합니다. 파일명: `YYYY-MM-DD_<주제-슬러그>.md`.
4. 저장 전에 "초안 파일을 Drive 폴더에 만들겠습니다. 제목: ..."로 한 줄 고지합니다.

## 출력 포맷

Claude Code 대화에는 3개 초안 전문을 모두 보여주고, 마지막에:

```markdown
---
✅ Drive에 저장됨: `2026-04-23_주제-슬러그.md`
- URL: https://drive.google.com/...
```
