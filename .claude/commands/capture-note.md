# 메모 캡처

## 사전 조건

1. `config.local.md`에서 **메모/아이디어 DB ID**를 읽습니다. 없으면 "Notion DB ID를 `config.local.md`에 먼저 등록해 주세요"라고 안내하고 중단합니다.

## 수행 단계

1. 인자 `$ARGUMENTS`를 확인합니다.
   - 인자가 `conversation` 또는 비어 있으면: 직전 대화 흐름에서 핵심 아이디어/결정사항을 3~7개 불릿으로 요약해 메모 본문으로 씁니다.
   - 그 외 텍스트면: 해당 텍스트를 그대로 메모 본문으로 쓰되, 첫 줄을 제목으로 승격합니다.
2. Notion `notion-fetch`로 메모 DB 스키마(속성명)를 한 번만 확인합니다 (title, 태그, 날짜 등 컬럼명이 사용자 DB마다 다르므로).
3. `notion-create-pages`로 메모 DB에 신규 페이지를 생성합니다.
   - 제목: 본문 첫 줄 (50자 초과시 말줄임)
   - 본문: 마크다운 블록으로 변환
   - 생성일: 오늘 날짜

## 출력 포맷

```markdown
✅ 메모 저장됨
- **제목**: ...
- **URL**: https://www.notion.so/...
- **본문 미리보기**: ... (최대 3줄)
```

생성 전에 제목과 대상 DB명을 한 줄로 고지 후 쓰기를 진행합니다.
