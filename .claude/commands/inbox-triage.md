# 받은편지함 분류

## 사전 조건

1. `config.local.md`에서 중요 발신자 화이트리스트와 자동 필터링 키워드를 읽습니다.
2. Gmail `list_labels`를 호출해 사용 가능한 라벨을 파악합니다 (현재 세션에서 라벨 부착은 수동 안내).

## 수행 단계

1. `search_threads`에 `is:unread` (또는 사용자가 다른 쿼리를 인자로 주면 그것)로 최근 미읽음 스레드를 최대 30개 가져옵니다.
2. 각 스레드를 다음 4개 버킷 중 하나로 분류합니다:
   - **🔴 긴급·답장 필요**: 화이트리스트 발신자 + 질문/요청 포함
   - **🟡 확인 필요**: 중요하지만 즉답 불필요 (청구서, 일정 안내 등)
   - **🟢 참고**: 뉴스레터·정보성
   - **⚪️ 자동 처리 후보**: 광고·프로모션·자동 필터링 키워드 매칭
3. 🔴 버킷의 각 스레드에 대해 `get_thread`로 본문을 확인한 뒤, `create_draft`로 답장 초안을 생성합니다 (한국어, 간결하게). 초안 생성 전에 사용자에게 "스레드 N건에 답장 초안을 만들겠습니다"라고 알립니다.

## 출력 포맷

```markdown
# 받은편지함 분류 (N건)

## 🔴 긴급·답장 필요 (n건) — 초안 생성됨
| 발신자 | 제목 | 답장 요지 |
|---|---|---|
...

## 🟡 확인 필요 (n건)
...

## 🟢 참고 (n건)
- 제목 — 발신자 (한 줄 요약)

## ⚪️ 자동 처리 후보 (n건)
> 라벨링 도구가 현재 비활성. Gmail 필터 규칙 수동 설정을 권장합니다. 대상 쿼리: `from:(...)`
```
