# 리뷰 소셜 자동화

## 사전 조건

1. `config.local.md`에서 아래 항목을 읽습니다.
   - **주 Gmail 주소**
   - **리뷰 Gmail 레이블** (없으면 subject 키워드로 대체)
   - **리뷰 DB ID** (Notion, 수집 원문 저장용)
   - **콘텐츠 아이디어 DB ID** (Notion, SNS 초안 저장용)
   - **초안 저장 폴더 ID** (Google Drive, SNS 파일 저장용)
2. 인자 `$ARGUMENTS`가 비어 있으면 `7d`(최근 7일)로 간주합니다.

---

## 1단계 — 리뷰 수집

Gmail `search_threads`를 아래 쿼리로 호출합니다:

```
(label:리뷰 OR label:후기 OR subject:(리뷰 OR 후기 OR 별점 OR 평가 OR feedback OR review)) newer_than:$ARGUMENTS is:unread
```

각 스레드에서 다음을 추출합니다:
- **발신자** (이름 + 이메일)
- **제목**
- **본문 핵심 내용** (200자 이내 요약, 민감 내용 마스킹)
- **감정 분류**: `긍정` / `부정` / `중립`
- **추정 별점**: 1–5 (명시 없으면 감정으로 추정)
- **주요 키워드** (최대 3개)

수집 결과를 표로 정리 후, `config.local.md`에 **리뷰 DB ID**가 있으면
`notion-create-pages`로 각 리뷰를 개별 페이지로 저장합니다.
저장 전에 한 줄 고지: "Notion 리뷰 DB에 N건 저장하겠습니다."

---

## 2단계 — AI 응답 초안 생성

각 리뷰에 맞는 이메일 답장 초안을 `create_draft`로 생성합니다.
생성 전에 한 줄 고지: "Gmail 초안 N건을 생성하겠습니다."

### 감정별 응답 가이드라인

| 감정 | 구조 |
|------|------|
| **긍정** (⭐4–5) | 진심 어린 감사 → 구체적 내용 언급 → 재구매·추천 유도 CTA |
| **부정** (⭐1–2) | 불편 공감 → 구체적 해결책 제안 → 후속 연락 안내 |
| **중립** (⭐3) | 감사 + 개선 의지 표명 → 추가 피드백 요청 |

- 모든 답장: 2–4문단, 공손하고 인간적인 톤, 한국어
- 발신자 이름으로 퍼스널라이징
- 초안이므로 실제 발송 전 검토 권장

---

## 3단계 — SNS 콘텐츠 생성

**긍정 리뷰 (⭐4–5)** 만 대상으로 SNS 소셜 증거 콘텐츠를 생성합니다.

### 생성 포맷

**X 스레드 (5–7 트윗)**
- 1번 트윗: 훅 — 리뷰 인용 or 놀라운 수치
- 2–5번: 고객 경험 → 가치 설명 → 내 관점
- 6–7번: CTA (팔로우, 링크, DM 유도)
- 각 280자 이내, 번호 미포함

**LinkedIn 포스트 (400–600자)**
- 1인칭, 짧은 문단, 줄바꿈 풍부
- 리뷰 내용을 자연스럽게 녹여 스토리텔링
- 말미에 독자에게 질문 1개

### 저장 위치

- Google Drive `초안 저장 폴더 ID`에 마크다운 파일 저장
  - 파일명: `YYYY-MM-DD_review-snscontent.md`
  - 형식: X 스레드와 LinkedIn 포스트를 `---`로 구분
  - 저장 전 고지: "Drive 폴더에 SNS 초안 파일을 만들겠습니다."
- `콘텐츠 아이디어 DB ID`가 있으면 Notion에도 각 포스트를 페이지로 저장

---

## 최종 출력 포맷

```markdown
## 리뷰 수집 결과
| # | 발신자 | 감정 | 추정 별점 | 핵심 내용 |
|---|--------|------|-----------|-----------|
| 1 | ...    | 긍정  | ⭐⭐⭐⭐⭐  | ...       |

## AI 응답 처리
- Gmail 초안 생성: N건 ✅
- 긍정 리뷰 초안 발송 전 검토 필요

## SNS 콘텐츠 생성
- 대상 긍정 리뷰: N건
- Drive 저장: `YYYY-MM-DD_review-snscontent.md` ✅
  - URL: https://drive.google.com/...
- Notion 저장: N건 ✅ (해당 시)

> 리뷰 답장 초안은 Gmail 임시보관함에서 확인 후 발송하세요.
```
