# 일정 요약

## 사전 조건

1. `config.local.md`에서 기본 캘린더 ID, 업무 시간, 집중 시간 최소 단위를 읽습니다.

## 수행 단계

1. Calendar `list_calendars`로 사용 가능한 캘린더를 확인합니다 (기본 캘린더 ID 검증용, 첫 호출에만).
2. `list_events`로 다음을 병렬 조회:
   - 오늘 (00:00–23:59, 사용자 타임존)
   - 이번 주 남은 일자 (오늘 다음날부터 일요일까지)
3. 오늘의 업무 시간 내에서 이벤트가 없는 연속 구간을 계산해, 사용자의 "집중 시간 최소 단위" 이상인 블록만 추천 후보로 선정합니다.
4. (선택) 사용자가 인자로 "N분 회의 시간 잡아줘" 같은 요청을 주면 Calendar `suggest_time`을 호출합니다.

## 출력 포맷

```markdown
# 일정 요약 (YYYY-MM-DD)

## 오늘
| 시간 | 이벤트 | 장소/링크 |
|---|---|---|
...

**집중 시간 추천**:
- HH:MM–HH:MM (N분)
- HH:MM–HH:MM (N분)

## 이번 주 남은 일정
- **MM/DD (요일)**
  - HH:MM 이벤트명
  ...
```

이벤트가 없으면 "오늘 일정 없음. 집중 블록: 업무 시간 전체"로 출력합니다.
