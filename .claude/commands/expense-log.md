# 경비 기록

## 사전 조건

1. `config.local.md`에서 **경비 DB ID** (없으면 Notion 메모 DB로 폴백)를 읽습니다.
2. 인자 `$ARGUMENTS`가 비어 있으면 "경비 내역을 알려주세요. 예: `/expense-log 택시 12000 교통`"로 안내 후 중단.

## 수행 단계

1. **파싱**: 자연어에서 다음 필드를 추출.
   - 금액 (숫자 + 통화, 기본 KRW)
   - 항목 (업체명 또는 사용 내역)
   - 카테고리 (식비/교통/구독/사무용품/접대/기타 중 추론)
   - 메모 (나머지 자유 텍스트)
   - 날짜 (명시 없으면 오늘)

2. **확인**: 파싱 결과를 1줄로 고지.
   예: "💸 2026-04-23 스타벅스 아메리카노 4,500 KRW (식비) — 기록합니다."

3. **저장**: Notion `notion-fetch`로 경비 DB 스키마 확인 (한 번) → `notion-create-pages`로 행 생성.

4. (선택) `config.local.md`에 **월 예산**이 적혀 있으면, 이번 달 누적 지출을 `notion-search`로 집계해 "이번 달 {X}/월 예산 {Y} = {Z}%" 한 줄 피드백.

## 출력 포맷

```markdown
✅ 경비 기록됨
- 📅 2026-04-23
- 💰 4,500 KRW (식비)
- 📝 스타벅스 아메리카노
- 🔗 https://www.notion.so/...

> 이번 달 식비 누적: 123,400 / 200,000 KRW (62%)
```
